# Tokenly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu-bar app that shows Claude Code and Codex subscription limits (5h + weekly % and reset time) in the top bar.

**Architecture:** One Swift file, no dependencies. Claude's numbers come from a 2-line addition to the existing `~/.claude/statusline.sh` that saves `.rate_limits` to `~/.claude/.usage.json`. Codex's numbers come from the newest `rate_limits` event in `~/.codex/sessions/**/*.jsonl`. App polls every 60s and renders an `NSStatusItem`.

**Tech Stack:** Swift (`swiftc`, AppKit), bash + jq (already used by the statusline). No Xcode project, no packages.

**Spec:** Approved in chat 2026-11-24 (not a file). Summary: title `C 42% · X 7%`; menu shows 5h + weekly % and reset time per tool; stale data (>1h) dimmed with "last update"; no Dock icon; **non-goals:** cost tracking, OAuth endpoint, notifications, settings UI.

## Global Constraints

- App name: **Tokenly**. Bundle id `local.tokenly`. `LSUIElement=true` (no Dock icon).
- Single source file `Tokenly/main.swift`; build with `swiftc` only.
- Poll interval 60s. Stale threshold 3600s.
- Claude data file: `~/.claude/.usage.json`. Codex data: `~/.codex/sessions/**/*.jsonl`.
- Do not touch the rest of `~/.claude/statusline.sh`; do not read Keychain or any credential.
- Not a git repo: no commit steps.

## Review Focus

- Codex: session file path date ≠ last event date (resumed sessions) → pick by **mtime**, scan lines from the end.
- Codex: newest file has no `rate_limits` event → fall back to the next-newest file, never crash.
- Last JSONL line truncated/malformed (file being written) → skip it.
- `resets_at` already in the past → show "reset", not a stale percent.
- Claude file missing or empty (statusline never ran) → show `C —`.
- Percent arrives as float (`6.0`) → display `6%`.

### Task 2: Parsers + self-check

**Files:**
- Create: `Tokenly/main.swift` (parsers section + `--selftest`)

**Interfaces:**
- Produces:
  - `struct Window { let percent: Double; let resetsAt: Date }`
  - `struct Usage { let fiveHour: Window?; let weekly: Window?; let updated: Date }`
  - `func parseClaude(_ data: Data) -> Usage?` — reads the Task 1 file shape; nil if `rate_limits` null/missing.
  - `func parseCodex(lines: [String], updated: Date) -> Usage?` — scans from the last line backwards for the first valid JSON line with `payload.rate_limits`; maps `primary`→`fiveHour`, `secondary`→`weekly`, using `used_percent` and `resets_at` (epoch seconds); nil if none.
  - `func loadCodex(root: URL) -> Usage?` — files sorted by mtime desc, first file where `parseCodex` is non-nil.
  - `func label(_ u: Usage?, now: Date) -> String` — `"42%"` from `fiveHour.percent` rounded; `"—"` if nil; `"0%"` if `resetsAt < now`.

- [ ] **Step 1: Write failing self-check** (`func selftest()` run by `Tokenly --selftest`, using inline fixture strings):
  - Codex fixture line from this machine: `{"type":"event_msg","payload":{"type":"token_count","rate_limits":{"primary":{"used_percent":6.0,"window_minutes":300,"resets_at":1795415302},"secondary":{"used_percent":7.0,"window_minutes":10080,"resets_at":1795757096}}}}` → `parseCodex` gives `fiveHour.percent == 6.0`, `weekly.percent == 7.0`.
  - Same fixture preceded by a line with no `rate_limits` and followed by a truncated line `{"type":"ev` → still returns 6.0 *(Review Focus: malformed last line)*.
  - Lines with no `rate_limits` at all → `nil` *(newest file without events)*.
  - `label` with `percent: 6.0` → `"6%"`; `nil` → `"—"`; `resetsAt` in the past → `"0%"`.
  - `parseClaude` on a fixture using the real shape recorded in Task 1; on `{"ts":1,"rate_limits":null}` → `nil`.

- [ ] **Step 3:** Implement the five functions above with `JSONSerialization`; no third-party code. `loadCodex` enumerates with `FileManager.enumerator`, reads only the 3 most recent files by mtime.
